# AgroFrotas

Este repositório não contém a aplicação web original em si. O arquivo `appConfig (1).json` é uma configuração de wrapper de app móvel (GoNative/Median) e aponta para a URL pública:

- https://agro-frotas-copy-621ac834.base44.app

Como o projeto real não está no GitHub, o que foi reconstruído aqui foi um wrapper local simples para abrir a aplicação configurada em um navegador.

## Como executar

1. Abra o terminal na pasta do projeto.
2. Execute:

   ```bash
   npm start
   ```

3. Acesse:

   ```text
   http://localhost:3000
   ```

O site local redireciona para a URL da aplicação configurada.

## Observação

Se o código fonte real da aplicação for disponibilizado, ele deve substituir este wrapper. O arquivo `appConfig (1).json` por si só não é um projeto de frontend completo; ele é apenas a configuração do app mobile.
